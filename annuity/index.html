계산 기준과 이용 안내 ＋

2024.12.17 버전의 ‘연금액 계산’ 화면을 옮긴 참고용 계산기입니다. 보험회사의 공식 앱이 아니며, 현재 판매 조건이나 요율을 확인하는 서비스가 아닙니다.

  • 원본 기본 설정과 동일하게 공시이율 입력값 0%, 추가납입·중도인출·행복이벤트자금 0을 적용합니다. 숨김 시트의 해약환급금·펀드수익률·LTC 계산은 제공하지 않습니다.
  • 최저연금기준액은 누적 납입보험료에 매월 연단리 이율의 1/12을 더합니다. 100세연금형은 경과 20년 이내 7% / 이후 5%, 종신연금형은 6% / 4%입니다. 이 비율은 보험료의 투자수익률이 아닙니다.
  • 연금연액 = 연금기준금액 × 성별·개시나이별 기초지급률 × (1 + 장기유지가산률). 원본처럼 나이 구간별 요율을 적용하며, 75~80세는 같은 구간입니다.
  • ‘100세까지 총연금액’은 원본 화면과 같이 연금연액 × (100 − 개시나이)입니다. 종신연금형의 지급이 100세에 끝난다는 뜻은 아닙니다.
  • 표시 금액은 원 단위 반올림이며 계산 중에는 반올림하지 않습니다. 최소 월보험료 30만 원과 납입완료 후 개시 조건을 확인합니다. 실제 가입 가능 여부는 별도 확인이 필요합니다.

검증 범위: 원본 저장 사례(40세 남성 / 월 50만 원 / 10년납 / 65세 개시)의 월별 기준액 300개와 연금 결과를 대조했습니다. 변경 조건의 Excel 재계산 대조는 아직 완료되지 않았습니다.
